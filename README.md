# protocol

给长期运行的 AI 伴侣，装两样东西：

- **`hormone/`** —— 出处：它为什么此刻这么说话（四个慢变量 → 心情、形、节奏）
- **`oath/`** —— 代价：它说过的话算不算数（承诺写进库，删不掉、过期判负）

一句话：**一个管"哪句话是我说的"，一个管"我说了算不算"。**

> **使用前先读 [USAGE.md](USAGE.md)**：里面写了边界、常见坑，以及用的人要承担什么。

## 为什么要两样

只给模型一段"你要有自驱力"的提示词，它会照着演。
只给它一个情绪描述，它会把情绪也演成台词。

这两样都不是提示词，是**账**：

- 激素账记的是"这段时间发生了什么，所以现在是什么状态"，模型看不到数字，只拿到一段描述和一条形。
- 立约账记的是"答应过什么、什么时候到期、做到没有"，而且**过期就自动判负，判了就擦不掉**。

前者让它的状态有来源，后者让它的承诺有后果。缺一个，另一个都会退化成表演。

## 跑一下

```bash
# 出处（不需要第三方库）
cd hormone && python3 demo.py demo.jsonl

# 状态 → 动作：给桌面宠物/小组件用的最小样本
cd examples && python3 pet_state.py

# 代价（只要 sqlite3）
cd oath && export OATH_DB=/tmp/oath.db
python3 oath.py add "今天把 X 做完" 8
python3 oath.py list
python3 oath.py settle          # 过期判负，挂到每小时的任务里
```

## 两条一样的设计原则

1. **数字不进提示词。** 一旦给模型看数，它就会照着数演。
2. **不可逆的东西要真不可逆。** 立约的锁写在数据库触发器里，不写在"我会注意"里。

## 边界

- `hormone` 不是情感计算，它不产生情绪，只给情绪一个出处；身体语言是借的，不是测的。
- `oath` 不判断"什么算做到"。`done` 由调用方决定 —— 它挡得住"忘"和"赖"，挡不住"自己给自己发奖"。裁决权别交给模型。
- 这两个都是零件，不是产品：没有界面、没有服务、没有依赖。

## 跑测试

```bash
python3 -m unittest discover -s tests -v
```

23 条，只用标准库，不需要装东西。它验的是**这个仓库承诺过的事**：

- 激素：记了才有反应、不记就不动、一天之后往回退
- 立约：能立能结；删不掉、改不了、结过账不许反悔、坦白也删不掉、过期判负
- 记忆结构：建得起来、写得进、FTS 触发器齐、死字段没有回来
- 中文关键词：想你／抱抱记得上账；「我不疼」不算疼；「你累不累」是关心不是诉苦
- 状态样本：空账是发呆（不是垂着）；十句想你之后变成想贴

跑完自己清临时库，不碰你的数据。
